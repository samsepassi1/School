Question 5: Which data analysis method you find to be the most insightful or helpful?
Answer: The .info() method is the most insightful because it provides a complete picture in one call: the number of non-null entries per column, the data type of each column, and total memory usage. This is especially valuable with large datasets because you can immediately identify which columns have missing values and which will need type coercion before analysis — without having to write separate .isnull().sum() and .dtypes calls.

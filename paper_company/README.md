# Beaver's Choice Paper Company — Multi-Agent Sales System

A multi-agent sales system implemented with **pydantic-ai** that processes
free-text customer quote requests for a paper-products company. Agents
collaborate to parse the request, check inventory, generate a priced quote
(with bulk discounts and urgency premiums), and either fulfill or decline
the order — all backed by a SQLite database.

## Layout

```
paper_company/
├── project_starter.py        # SQLite schema, seeds, 7 helper functions
├── quote_requests_sample.csv # 20 customer requests (mix of fulfillable / decline)
├── test_results.csv          # generated by run_eval.py
├── main.py                   # single-request CLI demo
├── run_eval.py               # batch runner over quote_requests_sample.csv
├── diagram.md                # Mermaid agent workflow diagram
├── report.md                 # reflection report
├── models/schemas.py         # Pydantic IO models for every agent
├── tools/                    # @agent.tool wrappers around the 7 helpers
└── agents/                   # parser, inventory, quoting, sales, orchestrator
```

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # then edit .env to set OPENAI_API_KEY
```

## Run

```bash
python project_starter.py     # initialize DB and print opening financial report
python main.py                # single demo request through the orchestrator
python run_eval.py            # batch run over quote_requests_sample.csv
```

`run_eval.py` writes `test_results.csv` and prints a summary (fulfilled vs
declined counts and final cash balance).

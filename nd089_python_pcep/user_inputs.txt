Question 5: Which data analysis method you find to be the most insightful or helpful?
Answer: The .info() method is the most insightful because it provides a complete picture in one call: the count of non-null entries per column, the data type of each column, and total memory usage. This is especially valuable with large datasets because you can immediately identify which columns have missing values — for example, price has only 44 non-null values out of 100 — and which will need type coercion before analysis, without needing to write separate .isnull().sum() and .dtypes calls.
